/Conectar CD

Conectar un nuevo CD a la red

Cada centro de distribución vive como un objeto dentro del arreglo cds del bloque CONFIG. Para activar uno nuevo:

  1. Abre el código de este archivo y ubica el bloque PLANTILLA DE CD comentado dentro de CONFIG.
  2. Duplícalo, asigna id, nombre, ciudad y cliente del CD real.
  3. Define sus pilares y registra cada aplicación con su proceso, estado y url.
  4. Guarda el archivo: el CD aparece en la red y su ventana queda operativa de inmediato.
